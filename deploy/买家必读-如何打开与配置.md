## RepoSensei 是干什么的

**给它一个本地代码项目，15 分钟看懂它。** 适合：接手别人的老项目、学习 GitHub
上的开源项目、入职熟悉新代码库。

- 🗺 **一键分析**：自动读完整个项目，给你技术栈、模块划分、架构图（可缩放导出）、
  入口文件、建议阅读顺序
- 💬 **针对项目问答**：像问老师一样问「登录是怎么实现的？」，回答会**引用真实源码
  文件和行号**，点一下直接跳到那行代码
- 🔍 **代码搜索**：搜函数名、类名、任意代码，点结果直接定位到行
- 🔬 **深度分析**：数据流 / 安全面 / 测试质量多视角报告
- 📄 **导出**：项目总结一键导出 Markdown，方便存档、分享
- 🔒 **本地优先**：代码不上传到任何中间服务器，只在你和 AI 厂商之间直连

## 第 2 步：第一次打开（关键，务必按这个来）

因为本版**没有做苹果付费签名**（省下 $99/年成本，让 App 更便宜给你），
macOS 第一次会拦一下。这不是病毒，是苹果对"非商店 App"的默认保护。**只需操作一次**。

### 方法 A（推荐，最省事）：右键打开

1. 打开「应用程序」文件夹，找到「RepoSensei」。
2. **右键点击**它 → 选择「**打开**」。
3. 弹窗里再点一次「**打开**」。
4. 之后就能像普通 App 一样双击用了。

### 如果方法 A 提示"已损坏，无法打开"

这是新版 macOS（Sonoma/Sequoia）对未签名 App 更严格导致的，
一条命令解决。打开「**终端**」（聚焦搜索 Terminal），粘贴下面这行回车：

```bash
xattr -cr /Applications/RepoSensei.app
```

> 这行命令的意思：清除 macOS 给下载文件打的"隔离"标记。只对这一个 App 生效，安全。
> 执行后再回到「应用程序」双击「RepoSensei」即可正常打开。

### 还是打不开？

- 去「系统设置 → 隐私与安全性」，往下滚，会看到一句
  "已阻止'RepoSensei'…"，点旁边的「**仍要打开**」。
- 实在不行，直接把这一步的截图发给卖家，会远程帮你搞定。

## 第 3 步：激活（一机一码，只需一次）

第一次打开 App，会看到「激活 RepoSensei」界面。上面有一串**本机识别码**
（形如 `U7L3O5HG2W7RWXQSUXOA`，20 位字母数字）。

1. 点识别码旁边的「**复制**」按钮。
2. 把这串识别码**发给卖家**（闲鱼私聊）。
3. 卖家会生成一个**专属激活码**（形如 `V2:U7L3O5HG2W7RWXQSUXOA.XXXXXXXX`）发给你。
4. 把激活码**粘贴**进输入框，点「**激活**」。
5. 激活成功 → 进入 App。**以后打开不再需要激活。**

> 🔒 为什么这样做：激活码和你这台 Mac 绑定，换电脑或转发给别人都用不了——
> 这是保护正版买家的设计。识别码只是一串哈希，不含你的任何隐私信息，可放心发送。
>
> 换新电脑了？在新电脑上重装、打开，会得到**新的识别码**，发给卖家换一个新激活码即可
> （正版买家的正常换机，卖家一般都会支持）。

## 第 4 步：配置你的 AI（BYOK 核心步骤）

激活后 App 会提示你配置 API Key——它还不知道用"谁的" AI。

### 4.1 先选一家大模型，去拿 Key

App 支持两类接入方式，**任选其一**即可：

| 接入方式 | 适合谁 | 去哪拿 Key |
|---|---|---|
| **OpenAI 兼容**（推荐） | 用 DeepSeek / Kimi / 各类中转代理的用户 | 对应平台注册 → API Keys → 新建。DeepSeek：platform.deepseek.com；Kimi：platform.moonshot.cn |
| **Anthropic 原生** | 有 Claude 官方账号，需海外支付/网络 | console.anthropic.com → API Keys → Create Key |

> 拿到的 Key 长得像 `sk-xxxxxxxxxxxxxxxx`。**复制它**（通常只显示一次，记得存好）。
> 注意：拿了 Key 通常还要在对应平台**充值几块钱**，否则调用会报"余额不足"。

### 4.2 在 App 里填 Key

1. 点右上角**齿轮图标**打开设置。
2. 「服务商」选你用的类型：
   - 用 DeepSeek/Kimi/中转代理 → 选「**OpenAI 兼容**」，填 **Base URL**
     （如 DeepSeek 是 `https://api.deepseek.com/v1`）和**总结模型**名
     （如 `deepseek-chat`）。
   - 用 Claude 官方 → 选「**Anthropic（原生）**」。
3. 在「API Key」输入框粘贴你的 Key。
4. 点「**测试连接**」——显示「已连接」就对了 ✅。
5. 点「**保存**」。

> 🔒 你的 Key 只存在你自己电脑本地，App 不上传、卖家看不到。

### 4.3 开始用

1. 回到主界面，点大按钮「**选择本地项目分析**」，选一个代码项目文件夹。
2. 等 1～2 分钟（界面有进度和秒数），AI 读完会给你：**项目总结 + 架构图 +
   建议阅读顺序**。
3. 右边聊天框里随便问：「入口在哪？」「登录是怎么做的？」「我应该先读哪个文件？」
   —— 回答里的 `文件名:行号` 都**可以点**，直接跳到对应源码。
4. 左边是文件树和代码搜索；中间看代码，选中一段可以右键「针对选中代码提问」。
5. 下次打开 App，首页有「最近的项目」，一键恢复，**聊天记录也还在**。

## 常见问题（FAQ）

**Q：为什么要我自己填 Key？别的 App 不用啊。**
A：因为本版不替你承担 AI 费用，所以更便宜、也更隐私（你的代码不经过任何中间服务器）。
你付给大模型厂商的是真实成本价，通常比"包月 AI App"划算得多。

**Q：分析一个项目要花多少钱？**
A：取决于项目大小和你选的模型。用 DeepSeek 分析一个中型项目通常几分钱到几毛钱；
后续问答更便宜。平台后台能看到用量明细。

**Q：测试连接失败 / 报错怎么办？**
A：依次检查：① Key 是否粘贴完整（没多空格）② Base URL 是否填对（OpenAI 兼容必填）
③ 对应平台是否已充值 ④ 网络能否访问该厂商（Claude 官方需海外网络）。
还不行把报错截图发卖家。

**Q：我的代码会上传吗？**
A：只发给**你自己选的** AI 厂商用于分析（这是 AI 能读懂你代码的前提），
不经过卖家或任何第三方服务器。项目总结、聊天记录都存在你自己 Mac 本地。
另外 App 会自动过滤 `.env`、密钥文件等敏感文件，**不会**把它们发给 AI。

**Q：激活码填了提示无效？**
A：最常见是三种：① 复制时多了空格 —— 整段重新复制粘贴，别手打；② 你把识别码
发错了（发的不是当前这台电脑的）—— 以 App 当前显示的识别码为准重新要码；
③ 卖家生成时用错了识别码 —— 把 App 上的识别码截图再发一次给卖家核对。

**Q：本机识别码发出去安全吗？**
A：安全。它是你 Mac 硬件标识的**单向哈希**，卖家（和任何人）都无法从它反推出你的
真实硬件信息，也不含任何账号/隐私。它唯一的用途就是让激活码和你这台电脑绑定。

**Q：换电脑怎么办？**
A：分两部分——
① **激活**：在新电脑重装、打开，会显示**新的本机识别码**，发给卖家换一个新激活码
（正版换机，卖家一般都支持）。旧电脑上的激活码在新电脑无效，这是正常的防盗版设计。
② **AI Key**：重新填一次自己的 API Key 即可。

**Q：支持 Windows / Intel Mac 吗？**
A：当前版本只支持 Apple 芯片的 Mac（M1 及以后）。买前请确认你的电脑型号
（ → 关于本机 → 芯片）。

**Q：能退款吗？**
A：软件类商品可复制，一般不支持"用过再退"。但如果是**打不开/无法配置**这类问题，
先找卖家，基本都能解决；确实解决不了再谈。
